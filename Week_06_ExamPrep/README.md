### Data structures and Programming - Seminar
# Week 6 - Linear DS exam prep

## Problems
**P1.** Given the head of a singly linked list, insert between each two values the numbers between them, i.e. for input: 1 -> 3 -> 6 -> 4, the output should be: 1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 5 -> 4.

**P2.** Write a function that from the head of a SLL removes all elements after the second that is not a product of the previous two elements.

**P3.** Reduce for a SLL given a function.
